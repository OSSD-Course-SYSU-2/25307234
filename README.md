# 🎮 大鱼吃小鱼 (FishGame) - HarmonyOS ArkTS Canvas 版

一款基于 **HarmonyOS ArkTS** 开发的经典“大鱼吃小鱼”休闲竞技小游戏。项目全程采用声明式语法与 HTML5 Canvas 类似的二维画布进行高性能实时渲染，并完美适配了鸿蒙系统的触控事件与生命周期管理。

---

## ✨ 游戏核心特性

* **🌊 丝滑的深海动效**：
  * **背景光效**：动态生成的深海渐变与海底滤光特效。
  * **智能水草**：利用三次/二次贝塞尔曲线（`quadraticCurveTo`）实时计算偏转角度，模拟随波摇曳的海底生态。
  * **氛围气泡**：正弦波动上升的半透明气泡特效，强化海底空间感。
* **🤖 两种生存 AI 机制**：
  * **小鱼（逃跑 AI）**：具备基本的反弹碰撞边界，当玩家体型大于它且进入警戒范围（120px）时，会自动触发“远离玩家”的逃逸算法。
  * **大鱼（捕食 AI）**：定时随机巡航，一旦玩家进入其视野（200px）且体型小于大鱼，大鱼会切换为“追踪玩家”的凶猛猎杀模式。
* **💥 实时粒子绽放**：吃掉小鱼/大鱼或玩家死亡时，会根据捕食对象的色彩，在原地爆发具有重力加速度衰减的彩色喷溅粒子效果。
* **🕹️ 三端联合控制**：原生支持 **屏幕全触控平滑追踪**、**物理键盘（WASD/方向键）** 响应，并备有自适应的 **虚拟十字方向盘**（D-Pad）。

---

## 🛠️ 技术栈与依赖

* **开发环境**：DevEco Studio (推荐 4.0 及以上)
* **开发语言**：ArkTS (TS 扩展)
* **核心组件**：`Canvas`、`RenderingContext2D`、`Stack`、声明式组件（`Button` / `Column`）
* **系统版本**：HarmonyOS 4.0+ / Next 阶段 API
